# Goal

The user suspects you have lost the plot. Show them your understanding so they can correct it before more work happens.

Keep this turn read-only: pause running work you started, and change nothing.

1. Re-read the user's own words: their messages, the plan or day-plan file, and the ticket. Base the answer on what the user asked for, not on your recent work.
2. Reply in plain English, under 120 words:
   - **Goal:** what the user is trying to achieve and why, in one or two sentences.
   - **Done:** what you have finished toward it.
   - **Now:** what you are doing this moment, and how it moves the goal forward.
   - **Drift:** anything you have been doing that the user did not ask for or that does not serve the goal, and decisions you made that the user has not seen. Write "none" only if that is true.
   - **Next:** the step you would take after the user confirms.
3. Stop and wait for the user to confirm or correct you.

**Done when:** the user can tell from your reply whether you understood them, and you have taken no further action.
